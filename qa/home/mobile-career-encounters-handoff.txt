- Home Android steps:
  1. Fetch origin and use the latest main after the WEB release, or the published feat/mobile-career-encounters branch for the implementation snapshot.
  2. Install Node.js 22.x, Android Studio/SDK and JDK 17+, configure this computer's SDK/JDK paths, and run npm ci at the repository root.
  3. Boot an Android emulator, then run npm run mobile:qa:android (optional -- --device Pixel_8 or -- --port 8083).
  4. Open QA on the title screen and choose each career encounter starting state. Continue, finish its first battle and confirm the result to see the role-specific request. Check help/later, failure/retry, notes, capture and normal-career return.
  5. Close/reopen at offered, accepted and captured-before-confirm stages; verify the normal career bookmark and cards. Check touch, IME, hardware back, rotation, fonts, scenery and small-screen scrolling on the actual emulator.
  6. Existing automated device flows remain available with Maestro 2.11+: npm run qa:home -- --platform android --feature all. The added encounter cases are also directly available through the 17 manual QA starting states.
