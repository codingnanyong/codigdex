- Home Android emulator steps:
  1. Check out feat/cod-218-platform-story from origin.
  2. Install Node.js 22.x, Android Studio/SDK and JDK 17+; configure JAVA_HOME and ANDROID_HOME for this computer.
  3. From the repository root, run npm ci.
  4. Start an Android virtual device in Android Studio Device Manager.
  5. Run npm run mobile:qa:android. This builds, installs and launches the native debug app, then starts Metro with the isolated QA save.
  6. Open QA on the title screen. Test tutorial, failure/retry, world progression, expeditions, secondary careers and close/reopen persistence.
  - Optional: npm run mobile:qa:android -- --device Pixel_8
  - Optional: npm run mobile:qa:android -- --port 8083
  - Windows alternative: start-mobile-qa.cmd --android
  - Automated native journeys additionally require Maestro 2.11+: npm run qa:home -- --platform android --feature all
  - macOS/iOS alternative with Xcode and CocoaPods: npm run mobile:qa:ios
