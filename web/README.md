# Codidex — web app

Next.js + Phaser.js game client. The repo root keeps policy/community-health files (`AGENTS.md`, `docs/`, etc.); this folder is the actual application.

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

## Vercel

Set the project's **Root Directory** to `web` when connecting this repo to Vercel.
